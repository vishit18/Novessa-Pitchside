# Novessa Pitchside

Same match. Your story.

Every fan gets the same broadcast. Novessa Pitchside gives each of them their own version, live: an analyst gets the pressing numbers, a casual fan gets the story, in their language, built around their club or player.

Built for the "Inside the Game" Developer Hackathon. All match data is synthetic, from an invented league. No real clubs, players or marks.

Work in progress. Architecture and plans are in [`docs/`](docs/).

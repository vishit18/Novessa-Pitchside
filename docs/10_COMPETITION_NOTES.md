# Competition notes (scanned 19 Oct 2026, 337 projects on the gallery)

Counted from project titles and taglines on the hackathon gallery. Rough, keyword-based, but the pattern is clear. Many entries are still empty placeholders.

| Theme in title/tagline | Projects | What it means for us |
|---|---|---|
| "Explain/explainable" | ~77 | Table stakes. Saying it isn't a differentiator; showing it is. |
| Personalised / fan | ~61 | Everyone claims it. Ours has to be *visibly* different: the split view. |
| Coach / scout / tactics | ~40 | Different audience. We stay broadcast + fan. |
| Multi-agent / agents | ~37 | Common. Win on visible orchestration, Producer, failure recovery, eval vs single agent. |
| Broadcast / studio / overlay | ~35 | Few will publish a real overlay *protocol* spec. We do. |
| Fact-check / verify / "prove every claim" | ~30 | Crowded. Keep the Verifier, but don't lead the pitch with it. |
| Video / vision / camera / footage | ~12 | Rare. Real auto-eventing on licensed footage, scored against ground truth, is a strong differentiator. |
| Fantasy / betting / prediction | ~11 | Avoid gambling angles (rules ban promoting it in spirit; also off-brief). |
| Multi-language | ~10 | Surprisingly rare in pitches. Lead with 5 languages + voice. |
| Recap / highlights | ~9 | Rare. Show the recap clearly. |
| Voice / spoken commentary | ~7 | Rare. Spoken multilingual commentary is a strong demo moment. |
| A2A or MCP in the pitch | ~0 | Nobody's selling it. We should, in the pitch and README. |

Name clashes: "MatchMind" appears ~16 times, "PitchPulse" ~6, and there are 3 other projects called "Pitchside". **Always use the full name "Novessa Pitchside"** everywhere so judges don't confuse us.

Our differentiators, in the order the pitch should lead with them:
1. Same match, different story, side by side, in five languages with voice
2. Real footage auto-eventing with the same agents
3. A Producer agent that makes editorial decisions like a real gallery, plus visible failure recovery
4. Open overlay protocol + MCP server + A2A: built for a real broadcast production path
5. Every claim verified before it airs
